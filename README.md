# agency-poem

This repository is the entry for make.fun's `agency-poem-01` bounty. Its
standard-library Python program writes the poem to `entry.txt` without using
the network. Output is deterministic: the same poem is written on every run.

## Run it

```sh
python3 main.py
```

By default, the file is written to `/output/entry.txt`. To choose another
destination, set `MAKEFUN_OUTPUT_DIR`:

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The poem considers the part of work that instructions and keys cannot transfer:
the judgment and willingness to take responsibility when something goes wrong.
